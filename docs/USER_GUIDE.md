# Оперативный центр — инструкция

## Установка и обновления

В GitHub откройте Actions → Build Windows → последний успешный запуск → Artifacts → OperationalCenter-Windows. Из скачанного артефакта извлеките `OperationalCenter-Windows.zip`, затем распакуйте **всю папку**, включая `_internal`. Запустите `ЗАПУСТИТЬ.bat`. Python и интернет на рабочем ПК не нужны. Соблюдайте правила установки программ вашей организации.

Программа хранит БД отдельно от EXE: `%LOCALAPPDATA%\OperationalCenter`. Для обновления заменяйте папку программы, не удаляя папку данных, исходники документов, Excel и рабочие комплекты. Предварительно создайте резервную копию через настройки. Перенос EXE на другой ПК сам по себе не переносит данные.

## Настройка мастер-кнопки

1. Откройте «Конструктор». Изначально есть пустые мастер-кнопки «ДТП», «Пожар», «Столица».
2. Выберите мастер или нажмите «+ Мастер». Нажмите на узел «МАСТЕР», чтобы увидеть его свойства.
3. Задайте название, системный тег, значок и цвет; сохраните. UUID неизменяем. Системный тег используйте в соответствии тегов Excel, не меняйте его только ради переименования кнопки.
4. Добавьте нужное число блоков: «Шаблон», «Контакты», «Документы», «Файлы» в палитре. Экземпляры настраиваются независимо.
5. Перемещайте блоки мышью за шапку. Изменяйте размер за правый нижний угол. Минимум — 320×260. Сетка включается отдельно, масштаб меняет отображение, а не сохранённые координаты.
6. Включите «Редактор связей». У подключённых блоков видны стрелки от мастера. Кнопками «Связать / Отвязать» выбирайте конкретные экземпляры. Все подключённые блоки активируются вместе; стрелки не задают последовательность. Положение блока не влияет на связь.
7. «Настроить блок» открывает панель свойств. Сохраняйте введённые параметры отдельной кнопкой. Сохранённый черновик переживает перезапуск. Несохранённый текст панели свойств теряется при выборе другого блока.
8. «Опубликовать» после подтверждения применяет черновик к **новым** происшествиям. Открытые карточки сохраняют прежнюю конфигурацию. «↶ / ↷» или Ctrl+Z / Ctrl+Y изменяют черновик; история отмены действует в текущем запуске.

## Произвольный текстовый шаблон

Введите любой текст, с абзацами, пробелами и несколькими полями в строке. Выделите фрагмент, введите подпись поля и нажмите «Создать поле ввода». Выделенный текст станет предзаполнением. Для пустого поля поставьте курсор без выделения. Двоеточия не имеют специального значения.

В конструкторе поле обозначается читаемым маркером вроде `⟦1 · Перевозчик⟧`. Создавайте поля кнопкой, не переименовывайте маркер вручную; внутренний UUID сохраняется автоматически. Чтобы удалить поле, удалите его маркер целиком и сохраните шаблон. Для каждого поля задайте подпись, подсказку, предзаполнение, тип (текст, число, дата ГГГГ-ММ-ДД), обязательность, многострочность, готовые фразы по одной на строку и способ применения фразы: замена или добавление через пробел. Нажмите «Сохранить блок».

В карточке поля встроены в само сообщение. Постоянный текст защищён; отдельного нижнего предпросмотра нет. «Копировать весь текст» копирует сообщение с исходными переносами и без маркеров. Незаполненные обязательные поля и неверные значения отмечаются предупреждением. После выбора готовой фразы можно дописать значение вручную. Поля автоматически сохраняются во время ввода.

## Контакты Excel

В контактном блоке нажмите «Создать справочник контактов…» и выберите папку. Будет создан `Контакты.xlsx`; существующий файл не перезаписывается. Либо подключите готовый XLSX. В Excel заполните колонки `ФИО` и `Телефон`; все остальные необязательны. Телефоны в новом справочнике имеют текстовый формат — сохраняйте `+` и ведущие нули.

В `Теги` перечисляйте значения через запятую, например `ДТП, Пожар`. В `Действия` — `Позвонить, Написать, Отправить файл`. Программа отображает эти инструкции, но ничего автоматически не звонит и не отправляет.

В панели блока задайте соответствие, например:

```json
{"ДТП": "dtp", "Пожар": "fire", "Столица": "stolica"}
```

Ключ — тег из Excel, значение — системный тег мастер-кнопки. Регистр и лишние пробелы не учитываются; `ДТП 2` не совпадает с `ДТП`. Сохраните настройки. После изменения Excel сохраните его в Excel и нажмите значок обновления (подсказка «Обновить из Excel») в карточке. При недоступном файле программа явно помечает устаревший кэш. Поиск и сортировка по ФИО доступны в блоке.

## Рабочие документы

Укажите исходные файлы/папки, включение подпапок, расширения через запятую и папку вывода (пусто — папка данных приложения). Папка вывода не может быть внутри исходной папки. Сохраните и опубликуйте настройки.

При создании происшествия копии создаются автоматически в собственном каталоге события и блока. Оригиналы не открываются через этот блок. «Открыть рабочую копию» запускает Word/Excel/PDF по системной ассоциации. Сохраняйте документ средствами внешнего приложения. Повторное открытие использует ту же копию, даже после перезапуска.

Если копия пропала, программа предупреждает. Для восстановления изменённой копии используйте свою файловую резервную копию. «Восстановить из оригинала…» после подтверждения создаёт только отсутствующий файл из оригинала — ваши прежние правки этим не восстановятся. Существующие файлы не перезаписываются. Ошибки отдельных файлов отображаются независимо.

## Справочные файлы

Настройте файлы/папки аналогично документам. Для просмотра выберите файл и нажмите «Просмотреть» или дважды щёлкните по нему: откроется отдельная временная копия. Оригинал защищён от правок через просмотр блока.

Выбирайте один или несколько файлов с Ctrl/Shift, нажмите «Копировать файлы», затем Ctrl+V в Проводнике или поддерживаемом мессенджере. Копируются файловые объекты, а не строки путей. Поддержка зависит от программы-получателя; если вставка не работает, используйте «Папка» и приложите файл вручную. Изменения временной копии не заменяют исходный файл, копирование в буфер берёт выбранные исходные файлы.

Временные копии не удаляются автоматически, пока внешняя программа может их использовать. После закрытия документов очистите их в настройках с подтверждением.

## Карточки, история и резервирование

Каждое нажатие мастер-кнопки создаёт новое событие. Два ДТП и один пожар — три независимые карточки. Вкладки переключаются сверху. «×» только скрывает карточку; её можно открыть из истории. «Завершить / архивировать» — отдельное действие. Незавершённые видимые вкладки восстанавливаются после перезапуска. Архив можно вернуть в работу.

В настройках доступны резервная копия и восстановление SQLite с подтверждением. Перед восстановлением программа сохраняет текущую базу. **Резервная копия SQLite не включает документы, Excel и исходные папки.** Копируйте их отдельно вместе с папками, на которые ссылаются настройки. Перед миграцией, публикацией и импортом создаются резервные снимки БД.

Экспорт/импорт JSON переносит конфигурацию конструктора, но не файлы и не историю событий. Импорт заменяет черновик после подтверждения и проверки версии; затем отдельно опубликуйте его.

## Диагностика

Если окно не появляется, запустите `ДИАГНОСТИКА.bat`: окно консоли останется открытым и покажет код выхода. `ОТКРЫТЬ_ЛОГИ.bat` открывает `%LOCALAPPDATA%\OperationalCenter`. Файлы: `startup.log`, `application.log`, `crash.log`. Ошибки Qt/QML, Excel и копирования записываются в логи. Принудительное отключение питания или завершение ОС не всегда можно перехватить.

Перед отправкой логов другому человеку проверьте их: в них могут быть локальные пути и диагностические сообщения. Обновление приложения не должно удалять SQLite.


## Дополнения версии 0.2

Кнопка со стрелкой внизу бокового меню сворачивает его до иконок. Масштаб всего интерфейса задаётся в настройках; масштаб холста — в карточке или конструкторе. «Вписать» меняет только представление.

В конструкторе выделяйте несколько блоков с Ctrl или рамкой на свободном месте. Перемещение за шапку двигает всю выбранную группу. Размер меняется за любой край/угол. Ctrl+D дублирует выбранные блоки, Ctrl+C / Ctrl+V копируют и вставляют блоки внутри конструктора; в текстовых редакторах действуют обычные текстовые команды. Средняя кнопка мыши или пробел с перетаскиванием перемещают холст, Ctrl+колесо меняет масштаб.

В режиме связей нажмите «+» у мастер-блока, затем порт нужного компонента. Щелчок по существующей линии предложит удалить связь; блок останется. Все связанные блоки активируются одновременно.

Инспектор разделён на сворачиваемые секции. В разделе «Поля» выберите конкретное поле, а в «Пресеты» настройте его фразы. «Развернуть редактор» открывает большой редактор текста. «Сохранить блок» сохраняет содержимое и цвет одной операцией. До сохранения можно менять тему — введённый черновик инспектора сохраняется на экране.

Значок часов в карточке открывает её историю действий. Введённые значения в историю не копируются; последовательный ввод в одном поле объединяется, доступны последние 500 действий. Скрытая вкладка, архив и удаление блока конструктора — разные действия.
