## Требует ручной приёмки

- Вставка в Проводник и конкретные рабочие мессенджеры — ручная приёмка на целевом ПК. Проверка CF_HDROP подтверждает файловый объект, но не поведение каждого получателя.
- Открытие в установленном Word/Excel/PDF, Windows 10/11, DPI 100/125/150%, антивирус/ИТ-политики и запуск без сети требуют проверки на целевом ПК.
- Одновременная работа нескольких копий программы с одной БД не является поддерживаемым пользовательским сценарием; SQLite использует транзакции и busy timeout.

## Ограничения, которые нужно учитывать

- Работа с большими файлами и Excel пока выполняется синхронно; на длительных операциях интерфейс может ждать окончания операции. Не закрывайте приложение до завершения создания комплектов.
- История отмены конструктора хранится в памяти текущего запуска. Черновик, опубликованная конфигурация, события, координаты и предпочтения — в SQLite.
- У редактора тегов Excel пока JSON-поле соответствий; ссылки файлов вводятся полными путями или через диалог.
- Поля шаблона представлены отдельными контролами и точным итоговым предпросмотром. Редактор конструктора показывает поля маркерами; рабочее сообщение их не содержит.
- Визуальные связи сейчас направлены от мастера к конкретным блокам. Произвольные цепочки блок→блок не вводились: активация всех связанных блоков одновременна.
- Резервные копии SQLite не включают внешние документы. Временные просмотровые копии очищаются явно.
- Копирование без перезаписи использует Windows rename без замены существующего файла; на Linux — hard link. NTFS/exFAT следует проверить на целевом ПК; Linux-файловая система без hard links безопасно вернёт ошибку.
- Автоматическое создание/очистка аварийных временных файлов не обещает восстановление несохранённых правок Word/Excel.

Автоматические Windows-проверки завершены. Полная приёмка на целевом Windows 10/11 ПК, включая Office и рабочие мессенджеры, пока не объявлена завершённой.
